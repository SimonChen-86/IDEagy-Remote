## 一、快速连接与密码登录

### 1.1 获取访问地址
当您在宿主机或云开发机运行专属启动器（Linux: `./start-linux.sh`、macOS: `./start-mac.sh`、Windows: `start-windows.bat`）后，终端将输出专属访问信息：

```text
================================================================
   🎉 Antigravity Web Remote 控制台已成功启动！
================================================================
📌 本地访问:    http://localhost:3000/
🌐 局域网/公网:  http://192.168.1.108:3000/
🔒 访问密码:    antigravity  (出厂默认密码，可在设置中修改)
💡 手机或笔记本浏览器打开上方网址，输入授权密码即可安全登录！
================================================================
```

### 1.2 访问授权密码登录
1. 在手机或笔记本浏览器中输入上述访问地址（若在局域网内，使用 `http://<开发机IP>:3000/`）；
2. 页面将呈现科技感全屏登录卡片：
   - 包含输入框：**【访问授权密码】**；
   - 输入您的工作台授权密码（**出厂默认密码**：`antigravity`）；
   - 点击 **【立即连接工作台】** 或直接按回车；
3. **安全凭据持久化 (7 天免登)**：
   - 验证通过后，系统会在本地安全建立端到端认证会话；
   - 默认提供 **7 天免登凭证**，在凭证有效期内刷新或重新进入网页无需再次输密；
4. **退出登录**：
   - 在主界面顶栏点击红色的退出图标（**LogOut**），即可一键清除本地认证凭据并退回登录界面。

> [!TIP]
> **安全防护提醒**：系统已从底层协议彻底屏蔽了在 URL 中明文附带 Token 的做法，彻底避免了浏览器历史记录或聊天记录转发导致密码凭据外泄。

## 二、双模态工作台与界面布局

系统内置自动响应式感知引擎，并在顶栏提供随时可点的切换按钮，支持在任意终端秒级自由切换：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        📱 vs 💻 双模态工作台布局                         │
├──────────────────────────────────┬─────────────────────────────────────┤
│ 📱 手机紧凑模式 (< 768px)          │ 💻 桌面工作台模式 (>= 768px)          │
├──────────────────────────────────┼─────────────────────────────────────┤
│ • 单列大拇指触控交互流             │ • 专业三栏 IDE 宽屏布局             │
│ • 顶部极简状态栏 (工程名/模型/模式)│ • 左栏：双卡片工程导航 + 会话恢复 + 模型│
│ • 底部滑出式文件成果预览抽屉     │ • 中栏：Agent 主视窗 + 思考流 + 悬浮输入│
│ • 悬浮底部 Dock 快捷 Prompt 栏     │ • 右栏：多格式实时预览面板 (平滑折叠)   │
└──────────────────────────────────┴─────────────────────────────────────┘
```

### 2.1 📱 手机紧凑模式 (Mobile Compact View)
- **单手流式操作**：针对移动端屏幕专门优化，操作按钮集中在大拇指易触达区域；
- **顶部轻量导航**：点击顶部工程名称可快速唤起工作区切换弹窗，顶栏右侧提供【模式切换】、【个性化设置】与【退出登录】；
- **底部抽屉式预览**：当需要查看生成的 Markdown 文档、HTML 页面或代码时，从底部滑出轻量抽屉面板，向下轻滑或点击把手即可收起。

### 2.2 💻 桌面工作台模式 (Desktop Workbench View)
- **左侧工作区栏**：
  - 双卡片项目面板（置顶常用工程 + 本地 IDE 历史激活工程）；
  - 【新建会话】与【恢复上次会话】按钮；
  - 底座模型选择与思考深度（LOW / MEDIUM / HIGH）配置胶囊。
- **中间 Agent 交互主视窗**：
  - 顶栏显示当前工程路径、Git 仓库状态徽标，以及清屏、右侧预览展开/收起按钮；
  - 流式打字机消息流、ThinkingBox 深度思维链、工具调用卡片；
  - 悬浮底部 Dock 输入框与快捷指令标签栏。
- **右侧多格式实时预览面板**：
  - 支持渲染预览 Markdown、HTML、PDF、代码高亮、图片；
  - 支持全屏沉浸式预览以及在新标签页独立弹窗打开。

### 2.3 自由切换工作模式
无论您当前使用的是手机、iPad、折叠屏还是笔记本 Chrome，只需点击顶部的 **手机图标（Smartphone）** 或 **电脑图标（Monitor）**，界面将瞬间重组，满足不同场景下的视野需求。

## 三、双卡片工程导航与多工作区管理

在左侧导航栏中，系统采用了业内创新的 **“双 Card” 工程项目管理体系**：

```text
┌──────────────────────────────────────┐
│  ⭐ 常用工程 (Pinned Workspaces)     │  <-- Card 1: 用户常用置顶工程 (优先展示)
│  ├── 📁 project-core (Git)           │
│  └── 📁 web-frontend (Git)           │
├──────────────────────────────────────┤
│  🕒 最近激活 (Recent Workspaces)     │  <-- Card 2: 自动探测 IDE 历史工程
│  ├── 📁 ideagy-backend [IDE同步]     │
│  └── 📁 mobile-app     [IDE同步]     │
└──────────────────────────────────────┘
```

### 3.1 Card 1：常用工程 (Pinned Workspaces)
- **功能定位**：将您日常高频迭代的核心工程置顶固定在最上方；
- **操作方式**：点击常用工程卡片右上角的 **【+】**，或打开【设置】面板中的【常用工程管理】，即可自由添加本地路径并为工程命名。

### 3.2 Card 2：最近激活工程 (IDE 实时同步)
- **功能定位**：Desktop Gateway 会自动检索宿主机本地 Antigravity IDE 的历史记录，提取最近活跃的工程项目；
- **无感同步**：带有 `[IDE同步]` 绿色徽标的项目即为本地 IDE 中打开过的工程，点击即可无缝挂接，无需手动输入复杂的绝对路径。

### 3.3 挂载全新工作区
1. 点击左侧栏的添加工程图标或在手机端点击顶部工作区名称；
2. 弹出 **【工作区选择与挂载】** 模态框；
3. 支持浏览开发机目录结构，选中目标文件夹后点击 **【挂载此目录】** 即可完成切换。

## 四、会话管理与智能记忆恢复

### 4.1 新建会话 (New Chat)
- 点击左侧栏显眼的 **【+ 新建会话】** 按钮；
- 界面将清空当前对话气泡，重置 Agent 上下文记忆，开启一个干净全新的会话；
- 底层会自动绑定新的 Conversation ID，不影响磁盘上的代码文件。

### 4.2 恢复上次会话 (Restore Session)
- **智能感知**：当某个工作区因闲置 20 分钟休眠，或者网关服务重启后重新切入该工程，系统会自动识别是否存在可恢复的历史会话；
- **一键热恢复**：若存在历史会话，左侧栏会亮起 **【🔄 恢复上次会话】** 按钮；
- 点击后，系统瞬间重新挂接上次退出的 Conversation ID，完整恢复智能体对本工程代码修改的记忆与对话上下文。

## 八、高危权限审批与双重安全模式

为了保障开发机环境的安全，防止模型意外执行破坏性指令，系统设计了完善的权限拦截与审批体系。

### 8.1 权限安全审批卡片 (Permission Action)
当智能体尝试执行涉及文件变更或系统命令的操作时，Web 端将弹出醒目的权限审批卡片：
- **卡片内容**：详细列出本次请求的操作类型（如“修改文件”、“执行终端命令”）、参数详情与目标路径；
- **决策操作**：
  1. **【单次允许】(Allow Once)**：仅放行本次操作；
  2. **【始终允许】(Allow Always)**：在当前会话中对同类型工具免审批放行；
  3. **【拒绝执行】(Refuse)**：驳回该操作，智能体将获知拒绝状态并尝试调整方案。

### 8.2 180 秒自动熔断超时机制
- 审批卡片上方配有 **180 秒倒计时进度条**；
- 若用户在手机息屏离线、网络中断或离开工位超过 180 秒未作出决策，系统将**自动触发超时拒绝 (Auto Refuse)**；
- 此机制坚决防止桌面端进程因等待用户输入而无限期挂死。

### 8.3 双重权限模式切换
您可以在【个性化设置】中按需选择适合的工作模式：
- **`always_proceed`（自主模式 - 推荐）**：智能体全自主流水线作业，自动放行常规读写，大幅提升编码效率；
- **`request_review`（严格审查模式）**：所有文件变更与高危命令均触发人工弹窗审批，适合对生产代码库进行高敏操作。

## 十、模型引擎与思考深度切换

### 10.1 全局唯一的模型选择区
在左侧导航栏的底部，配置了全局唯一的模型控制中心：
- **模型下拉选择框**：基于 `ModelService` 纯净化探测算法，自动收录并展现可用模型（如 `gemini-3.8-flash`、`gemini-3.1-pro`、`claude-3-7-sonnet`、`gpt-oss-120b` 等）；
- **参数变动热感知**：切换模型后，底层 `ProcessPool` 会自动检测参数变动，秒级平滑热重启子进程并继承当前会话状态。

### 10.2 Gemini 思考等级 (Thinking Effort)
针对 Gemini 系列大模型，支持自由调节思考预算等级：
- **LOW**：轻度思考，适合快速问答、语法修正与简单脚本；
- **MEDIUM**：均衡思考，适合常规功能开发与函数编写；
- **HIGH**：深度严谨思考（出厂默认推荐），适合复杂系统架构设计、算法排错与长链路重构。

### 10.3 非 Gemini 模型的解耦与安全保护
当您切换至 Claude 3.7 Sonnet 或开源模型时：
- 思考深度按钮栏会自动收敛置灰，并显示 **“固定思考深度 (Fixed)”**；
- 底层会自动剥离 `--effort` 参数，坚决防止非 Gemini 模型因参数不兼容导致启动报错；
- 当您切回 Gemini 时，先前的思考等级偏好会自动无缝恢复。

## 十二、常见操作疑问解答 (FAQ)

### Q1: 忘记了工作台访问密码怎么办？
**解答**：
密码保存在宿主机项目根目录下的 `gateway-config.json` 中。
1. 在开发机打开该文件，找到 `"server"` 节点的 `"password"` 字段；
2. 将其修改为您期望的新密码（或直接改回 `"antigravity"`）；
3. 执行 `./start-linux.sh restart`（或对应系统的重启命令）即可生效。

### Q2: 手机在局域网内打不开 Web 页面怎么办？
**解答**：
1. 请确认手机与开发机处于**同一个 Wi-Fi 或局域网子网**下；
2. 确认输入的是开发机真实的内网 IP（如 `192.168.1.108:3000`），而非 `127.0.0.1` 或 `localhost`；
3. 检查开发机防火墙设置：
   - Linux: 执行 `sudo ufw allow 3000/tcp`；
   - Windows: 在 Windows Defender 防火墙中放行端口 3000。

### Q3: 为什么切换到某些模型后，思考等级按钮变成了置灰的“固定思考深度”？
**解答**：
这是系统的智能保护特性。Claude Sonnet、GPT-OSS 等模型的思维深度预算由其模型底层直接决定，不支持外部传入 `--effort` 命令行参数。为了防止触发 CLI 异常，系统主动将其置灰显示，切回 Gemini 模型后即可恢复调节。

### Q4: 手机锁屏断开连接后，刚才智能体输出的进度会丢失吗？
**解答**：
不会。网关内部集成了 **Event Ring Buffer（事件环形缓冲区）**。当您解锁手机重新连入时，客户端会自动上报最后收到的序号，网关会自动追帧回放离线期间产生的流式消息与最新状态。

### Q5: 提示“模型配额已达上限 (Quota Exceeded)”如何处理？
**解答**：
当底层大模型账号的调用频次或日配额耗尽时，界面顶端会展示警示横幅并给出刷新时间提示。此时智能体会安全挂起。您可以：
1. 在左下角切换至其他可用的模型继续进行开发；
2. 或者等待配额倒计时刷新后点击输入框的【继续】指令。
